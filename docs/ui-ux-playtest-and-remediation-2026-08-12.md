# UI / UX 试玩审查与整改记录

日期：2026-08-12

执行分支：`codex/gameplay-expansion-r1`

范围：首次进入、教程、五年决策节奏、响应式工作台、键盘可达性与关键文案

## 1. 团队分工与验收方法

- 产品经理：审查首次体验负担、决策节奏、信息层级和中断频率。
- QA：在 390 × 844、800 × 900、1600 × 1000 三类视口复现问题，检查尺寸、焦点、暂停状态和目标年顺序。
- 开发审阅：检查教程、报告、周期复盘和机缘草案之间的状态机，以及事件监听器生命周期。
- 负责人：汇总优先级、实施修复、补回归测试，并进行最终全量校验。

验证不是只检查 DOM 是否“可见”，而是同时检查实际像素尺寸、滚动可达性、游戏年份是否推进、焦点所在区域和完整决策状态。

## 3. 已落地的产品调整

### 首次进入

- 保留五页精细设置，同时在第一页增加“使用当前情景的推荐配置快速开始”。
- 强制教程从六步缩减为三个任务：读取地图、做五年选择、承诺后开始。
- 图层、统计和移栽改为按需探索，不再阻塞首次开始时间。

### 教程状态机

- 打开教程时记录原暂停状态并强制暂停；关闭时仅在原本运行、存在活动策略周期且没有报告时恢复。
- 教程期间游戏年份保持不变。
- 移动端切换教程步骤时自动打开地图或策略抽屉，不再高亮屏外空区域。
- 文案改用 `＋ / −`、点按等跨设备操作，不再要求触屏用户使用右键或滚轮。
- 增加自动聚焦、Tab 约束、Escape 退出和焦点归还。

### 五年复盘与核心规则

- 第一个五年周期保留完整复盘，以便玩家学习因果证据。
- 第二个周期起改为右侧栏；移动端改为底部抽屉，地图仍然可见。
- 增加“沿用上周期配置”，选择或放弃机缘后可用第二次点击继续。
- 任何没有活动策略周期的状态都不能直接恢复时间；主控制必须完成机缘、预测和策略承诺。
- 最终五年周期复盘并入第 20/30 年情景结算，不再先要求承诺目标年之后的策略。
- 结算后进入沙盒时才抽取下一周期机缘，并保持暂停直到新承诺完成。

### 工作台与可访问性

- 手机和平板地图改为正常文档流，画布保持至少 320 px 高；策略和统计抽屉使用明确的 `dvh` 高度并可滚动。
- 移动端默认折叠图层树，隐藏无效的布局编辑按钮，并把主要触控目标提高到 40 px。
- 桌面策略内容允许纵向滚动，大字号下承诺区和碳账仍可到达。
- 机缘草案只在状态变化时重绘；周期弹层打开时，背景草案隐藏且不可聚焦。
- 报告和首次完整复盘增加焦点进入与背景 `inert`；重复的 `document` 监听器使用 `AbortController` 清理。
- 修复重复的 `map-scale-line` ID，并统一“阶段报告”“返回开局”“情景结算后解锁”等文案。

## 4. 自动化验收矩阵

| 验收项 | 断言 |
| --- | --- |
| 390 / 800 px 地图 | canvas 高度大于 300 px |
| 移动抽屉 | 策略、统计实际高度大于 300 px，承诺区可滚动到达 |
| 移动教程 | 策略步骤自动打开策略抽屉，下一步恢复地图，Escape 可关闭 |
| 教程暂停 | 运行中重播教程，等待 700 ms 后森林年份不变；关闭后恢复推进 |
| 机缘键盘操作 | 聚焦卡片并等待 600 ms，焦点仍在同一张卡 |
| 周期门禁 | 返回自定义后主按钮禁用，等待 800 ms 年份不变 |
| 复盘节奏 | 首周期 `full`，第二周期 `drawer`，沿用配置可在处理机缘后直接继续 |
| 目标年顺序 | 最终周期进入情景报告，不产生下一周期弹窗；报告关闭后才生成沙盒草案 |
| 桌面大字号 | 策略面板 `overflow-y: auto`，承诺区完整进入可视区域 |
| 性能基线 | 10,000 个体静止和运行态继续保持至少 30 FPS |

## 5. 后续可继续观察但不阻断本轮上线的项目

1. 用真实试玩记录比较“快速开始”和五页精细设置的完成率，决定是否把快速开始提升为默认主路径。
2. 记录复盘停留时间、沿用配置比例和自定义比例，验证侧栏复盘是否真的降低认知中断。
3. 将图层、统计、移栽改为基于首次操作的渐进提示，而不是重新扩充强制教程。
4. 后续若增加更多卡牌或情景，保持“同一时刻只有一个决策入口”和“任何时间推进都有活动承诺”两个状态机不变量。
