# Wiegand 森林模拟与游戏体验改进总结

记录日期：2026-10-14。依据：用户提供的两张讲座照片、2026-10-11 完成的原始来源核对，以及当时对本项目代码的检查。

状态：已完成总结；以下五个实验情景尚未运行，游戏功能尚未因此修改。完整引用和读图限制见[来源核对记录](wiegand-forest-simulator-sources-2026-10-11.md)。

## 程序身份与可确认的研究思路

正式名称拼作 **Programita**。官方将它定位为空间点格局分析软件：输入样地边界、树木坐标、物种及胸径等标记，计算聚集、邻居距离、物种关联等统计量，并生成随机点格局作为对照。[Programita 官方介绍](https://www.ufz.de/index.php?en=41413)

照片则显示一个具备生长、繁殖、存活、扩散和补充参数的森林动态模拟界面。照片未显示程序标题，其正式名称和版本仍待确认。2025 年华东师大的 Wiegand 报告与其主题高度吻合：以单株树为单位，用树大小和邻域拥挤描述生长，重现胸径分布及邻域空间格局。[华东师大报告介绍](https://tiantong.ecnu.edu.cn/show/1435)

可借鉴的核心流程是：设定初始森林与人口过程，持续计算各棵树的生长、死亡和补充，再汇总空间格局、胸径结构和群落变化。胸径分布是这些过程累积形成的输出。

## 从简单情景开始

下表是根据照片和研究思想整理的教学路线，不是照片程序已经核实的操作配置。

| 情景 | 新增输入 | 主要观察结果 |
|---|---|---|
| 1. 一批树一起长大 | 初始数量、初始胸径、增长速度 | 胸径分布窄峰移动，断面积增加 |
| 2. 持续补入小树并发生死亡 | 补充数量、进入胸径、存活概率 | 多个径级同时存在，数量与大小结构变化 |
| 3. 后代落在母树附近 | 扩散尺度与落点规则 | 同种聚集、空间斑块、邻域拥挤 |
| 4. 邻居影响生长 | 邻域范围、距离权重、同种及异种影响强度 | 个体生长分化、胸径分布和断面积变化 |
| 5. 物种差异与幼树建立 | 物种参数差异、同种密度对建立或存活的作用 | 幼树分布、物种丰度与共存格局 |

第二个情景可设计为：100 米 × 100 米地图，一个物种，初始 200 株、胸径均为 1 厘米；每年增长 0.2 厘米，年存活概率 98%，每年在随机位置补入 5 株胸径 1 厘米的新树，运行 100 年。此处年龄指进入模型后的时间。

这个实验尚未运行。按规则推导，持续进入的小树和随机死亡会形成多个径级，长期平均结构倾向于小径多、大径少。关闭补充与死亡，则同样大小的树形成一个向右移动的窄峰。后续可以单独把增长速度改为每年 0.4 厘米，或把年存活概率改为 95%，比较生长与寿命对结构的作用。

## 照片中的六组输入

| 输入组 | 可辨认内容 | 控制的过程 |
|---|---|---|
| 初始森林 | 样地与样方尺寸、物种数、每种个体数、读入样地数据 | 开始时有哪些树、在哪里、多大 |
| 背景人口过程 | 繁殖、成树存活、幼树存活 | 新树进入与已有树保留 |
| 扩散 | 扩散尺度、独立落点比例、聚集中心数量与变异 | 后代出现的位置 |
| 邻域作用 | 影响范围、距离权重、同种及异种作用系数 | 哪些邻居产生多大影响 |
| 生长与大小 | 生长曲线、大小效应、生长概率 | 个体长多快、何时进入更大径级 |
| 建立与成熟 | 幼树建立、进入胸径、繁殖大小阈值、时间滞后 | 后代能否留下及参与繁殖 |

可辨认读值包括物种数 258、繁殖参数 1.750、成树存活 0.995、幼树存活 0.915、邻域范围 10、扩散参数 7、模拟上限 500。时间和空间单位尚未核实；时间轴注明每步五年，模拟上限 500 不能直接解释为 500 年。宽 100、高 50 也可能表示网格数。勾选读入样地数据后，实际个体数未必来自“每种 1000 株”的合成初始化设置。

## 照片中输出的指标和图表

| 输出 | 回答的问题 |
|---|---|
| 树木空间地图 | 哪些物种在哪里聚集，形成何种斑块？ |
| 胸径分布 | 小树、中树、大树各有多少？ |
| 各径级胸高断面积 | 哪些大小的树贡献了较多树干截面积？ |
| 物种丰度分布 | 常见种与稀有种如何组成群落？ |
| 生长速度与胸径关系 | 不同大小的树长得多快？ |
| 胸径与年龄关系、达到 50 毫米胸径时的年龄分布 | 长到指定大小需要多久？ |
| 各径级平均死亡风险 | 哪些大小的树更容易死亡？ |
| 同种、异种及相互作用拥挤随胸径变化 | 不同大小的树面对怎样的邻域？ |
| 可繁殖树的拥挤分布、生长受抑制程度分布 | 个体之间的生长处境差异有多大？ |
| 聚集与分离的时间曲线及累积分布 | 同种是否扎堆，异种是否分开，格局如何变化？ |
| 聚集度与丰度关系 | 常见种与稀有种的空间组织是否不同？ |
| 原有与新增可繁殖树关系、补充及死亡记录 | 森林能否持续更新繁殖群体？ |

相互作用项的公式及部分曲线的具体统计定义仍待手册核实。第二张图标题包含“观测格局”，部分时间曲线为空，应首先视为观测数据或初始状态展示。缺少可见图例，不能统一指定红柱和蓝线分别代表实测或模拟。

## 对游戏体验的四项启发

1. **展示树木大小结构。** 当时游戏已经记录胸径、平均胸径、小中大径级比例和断面积，可增加胸径分布，叠加五年周期开始和结束的状态。
2. **让投资结果对应具体树木。** 展示五年中跨入更大径级的树数、幼树补充与保留，以及林窗后释放生长的位置。
3. **解释个体为何长得慢。** 点选树木后显示邻域范围和同种、异种邻居的贡献，并分别说明竞争与病原压力。
4. **用逐步增加机制的情景帮助学习。** 从生长与更新开始，再加入扩散和邻域作用；沿用同一随机种子重试，每次只改变一个因素。

报告还提供一个值得比较的机制：拥挤主要影响生长，死亡仍可随树大小变化。游戏可以将“受压减速”和“死亡风险”分别计算和反馈，帮助玩家观察树木等待林窗与恢复生长的过程。这个结果属于特定数据和模型，不表示所有森林和生活阶段都遵循同一死亡规则。[报告中的模型结果](https://tiantong.ecnu.edu.cn/show/1435)

## 下次阅读后的讨论入口

建议先确定是否优先做三项反馈：胸径分布、五年径级迁移、同种与异种邻域对生长的影响。确定后再设计参数和验证实验；本次保存文档不代表这些建议已经实施。
