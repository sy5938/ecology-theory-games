# Wiegand 森林模拟界面的来源核对

检索日期：2026-10-11。目的：用两张讲座照片及第一手材料，核对程序身份、参数到指标的关系，以及可用于生态学游戏的简单实验。此笔记没有运行照片中的程序，也没有验证其具体参数公式。

## 可以确认的程序身份

**正式拼写是 Programita。** Wiegand 所在 UFZ 的官方页面将其定义为空间点格局分析软件：主要输入树木位置、类别、大小等已有点数据，计算空间统计量，并通过泊松、聚集、软硬核等点过程或零假设生成对照点格局。官方页面列出的输出包含配对相关函数、L 函数、邻居距离、标记相关、空间 Simpson 指数和个体物种面积关系。它能生成随机空间格局，但这些功能不能直接证明它就是照片中逐步模拟繁殖、生长和死亡的森林程序。[UFZ：Programita](https://www.ufz.de/index.php?en=41413)

**照片更直接显示一个森林动态模拟界面，正式名称尚未确认。** 图片可见 `Start with plot data`、生长/存活/补充参数、树径与年龄图等；这些证明界面具备动态森林模型的控制及统计面板。照片没有显示程序标题，不能把其所有功能归为正式 Programita，也不能断言是 FORMIND。这里称它为“照片中的森林模拟器”。证据：用户所提供两张讲座照片。

2025-09-16 华东师范大学天童站的报告公告与照片主题高度吻合，题为 *Neighborhood crowding links statistical models of tree growth and survival with individual-based models to understand the tree size distribution and forest dynamics*。公告说模型以单株树为单位，利用树大小及邻域拥挤的幂函数描述生长，用 BCI 和长白山数据确定参数；模拟树径分布较快趋于稳态，并匹配若干邻域空间格局。**这能确认研究方法与目标，不能单凭公告确认照片属于某个公开软件版本。**[ECNU 报告公告](https://tiantong.ecnu.edu.cn/show/1435)

## 必须保留的读图限制

- `tmax = 500`：图的时间轴写 `Timesteps [5yrs]`，所以不能直接写“模拟 500 年”；若参数确为步数，才可能对应 2,500 年。
- `quadrat size = 10`、`plot width = 100`、`plot height = 50`：单位不明，不能直接写 100 m × 50 m。宽高也可能是 10 m 网格的数量，进而对应 1,000 m × 500 m 的 50 ha 样地，但这是待查的解释。
- `# species = 258`、`# trees/sp = 1000`：界面读值不能保证当前已载入样地使用这些合成初始化值；勾选 `Start with plot data` 时，文件可能提供实际物种及个体数。
- 第二张标题含 `observed patterns`，且若干时间图为空，更适合解释为实测数据或模拟初始状态的统计面板，不能当作已运行后的模拟结果。
- 红柱及蓝线在不同图中的具体角色没有可见图例。可以说“柱状分布与曲线对照”，不能统一断言哪个为实测、哪个为模拟。

以上限制均来自用户照片，而不是已经核实的软件手册。

## 照片中可辨认的输出

以下清单来自用户照片中的图题和控件；描述的是图表用途，不是已经核实的统计公式。

| 输出 | 可以回答的问题 |
|---|---|
| 树木空间地图，按物种及个体状态筛选 | 哪些树在哪里，形成何种斑块？ |
| 胸径分布 | 小树、中树、大树分别有多少？ |
| 按径级汇总的胸高断面积 | 哪些径级贡献了较多的树干截面积？ |
| 所有树的物种丰度分布 | 有多少常见种和稀有种？ |
| 生长速度与胸径关系 | 不同大小的树长得多快？ |
| 胸径与年龄关系；达到 50 mm 胸径时的年龄分布 | 树龄与树大小如何联系，到达指定大小需要多久？ |
| 按径级的平均死亡风险 | 哪些大小的树更容易死？ |
| 同种、异种及相互作用拥挤随胸径变化 | 不同大小的树处于怎样的邻域？相互作用项的定义待核实。 |
| 可繁殖树的同种、异种及相互作用拥挤分布 | 个体承受的邻域负荷是否差异很大？ |
| 拥挤对生长影响的分布 | 有多少树的生长受到较强抑制？具体横轴换算待核实。 |
| 聚集与分离的时间轨迹、累积分布 | 同种树是否扎堆，异种树是否分开；物种之间差异如何？ |
| 聚集度与丰度关系 | 常见种与稀有种的聚集方式是否不同？ |
| 原有可繁殖个体数与新增可繁殖个体数关系 | 成树补充与现有繁殖群体之间有什么联系？图题为繁殖时间滞后，具体统计定义待核实。 |
| 幼树、可繁殖树的数量、补充与死亡记录 | 森林正在补进新树，还是失去已有树？ |

## 参数与指标：可靠关系及不确定细节

| 输入或规则 | 可以有依据地解释的作用 | 主要观测输出 | 未核实部分 |
|---|---|---|---|
| 初始位置、物种、胸径；或读入样地文件 | 确定开始的群落结构 | 地图、树径分布、物种丰度分布 | 照片文件格式与具体列 |
| 生长率、大小效应 | 个体从小径级进入大径级；改变在各径级停留时间 | 生长与胸径关系、胸径分布、胸径与年龄、断面积 | `r_gr`、`c_gr` 等参数的确切方程 |
| 成树与幼树背景存活 | 改变个体能活多久、能否长到大径级 | 死亡风险、大小结构、断面积、出生死亡记录 | 存活数值按年还是按 5 年步长 |
| 繁殖与补充 | 向较小个体阶段补入新树 | 幼树数量、小径级数量、补充率 | `reproduction` 是种子数、幼树数或有效补充率 |
| 扩散距离 | 决定后代距母树或聚集中心的空间范围 | 聚集度、同种拥挤分布 | 照片的 `dispersal = 7` 的单位、核函数 |
| 独立于母树的落点比例、聚集中心数 | 改变后代与同种成树的空间联系 | 聚集—丰度关系、同种/异种邻域统计 | `indep comp` 是否对应文献里的 `p_d` |
| 邻域半径、距离权重 | 决定哪些邻树被计入、远近影响差异 | 同种、异种、加权相互作用的拥挤指数 | 照片是否计入邻树胸径或断面积 |
| 同种、异种对生长的效应 | 将邻域状态转换为实际生长变化 | 生长缩减分布、径级生长、大小结构 | `beta_gr`、`betaH_gr` 等的确切符号及变换 |
| 幼树建立或存活的密度效应 | 修改新树留下来的概率 | 幼树建立、死亡、聚集、多样性 | 具体 `betaEst` 公式与参数作用顺序 |

前四行的总体因果关系来自讲座介绍及通常的大小结构人口过程；扩散及聚集机制可由 Wiegand 2021/2025 年原始模型描述支持；照片专属变量公式均未核实。[ECNU 报告公告](https://tiantong.ecnu.edu.cn/show/1435)；[Wiegand 等，2025，Nature](https://www.nature.com/articles/s41586-025-08604-z)；[Wiegand 等，2021，Nature Ecology & Evolution](https://doi.org/10.1038/s41559-021-01440-0)

## 讲座模型与旧模型不能混用

**讲座关于死亡的结论是“拥挤影响生长，未识别到相应死亡作用”，并不是“所有树同样容易死”。** 公告原文使用 “constant but size-dependent rate”，所以至少要保留死亡可能随大小变化的描述；它没有提供死亡函数，不能将其进一步变成“大小无关的恒定死亡率”。这也是数据和特定模型的结果，不宜泛化为所有森林或所有生活阶段。[ECNU 报告公告](https://tiantong.ecnu.edu.cn/show/1435)

2025 年 Nature 论文 *Latitudinal scaling of aggregation with abundance and coexistence in forests* 的模拟器只包含能繁殖的成树，**没有大小差别**；每步为 5 年，先生成并放置新个体，再随机决定成树存活，以周期相接边界避免边缘影响。该模型可研究聚集、丰度、稀有种优势和共存，却不能直接生成真实树径分布。[论文 Methods；作者托管的全文 PDF](https://guochunshen.github.io/pdfs/publications/Wiegand%2C%20Wang%20et%20al.%202025%20-%20Latitudinal%20scaling%20of%20aggregation.pdf)

该旧模型每株平均产生 `r_f` 个新个体：比例 `1-p_d` 的后代被放在随机挑选的同种母树附近；其余 `p_d` 被放在独立于母树的随机聚集中心附近；两者使用二维高斯核。旧模型的同种拥挤是半径内同种邻树之距离倒数的总和，异种拥挤对异种做同样计算，相互作用拥挤再用物种对竞争强度加权。这个机制可帮助解释照片的扩散及拥挤分组，**不能证明照片用完全相同的公式**。[论文 Methods；作者托管全文](https://guochunshen.github.io/pdfs/publications/Wiegand%2C%20Wang%20et%20al.%202025%20-%20Latitudinal%20scaling%20of%20aggregation.pdf)

旧模型的一个对称实验使用 80 个物种、约 86,000 株树、200 ha、5,000 个时间步，每步 5 年；所有物种使用相同规则。设置同异种竞争系数相同、背景存活为 1、高斯扩散标准差为 10 m、同种系数 0.02、每步补充率 0.1，以获得约 430 株/ha 的树密度。它是论文实验配置，**不是适合直接复制进我们的游戏或照片程序的最简输入**。2025 论文说明 Delphi/Pascal 源码可在 2021 年前作补充材料找到。[论文 Methods 和 Code availability](https://www.nature.com/articles/s41586-025-08604-z)；[2021 前作及补充材料入口](https://doi.org/10.1038/s41559-021-01440-0)

## 从简单规则理解胸径分布

若只放入一批同样大小的树，以完全相同的规则生长，所得大小分布可能只是一个移动的窄峰。要形成持续包含小、中、大树的群落，应同时说明新树何时进入、胸径怎样增长、死亡怎样抽走个体。即便三个过程规则简单，个体在各径级停留时间和活到该径级的概率也会共同决定分布。因此胸径分布是运行后统计出来的结果，通常不是需要玩家填写的输入。[讲座模型目标](https://tiantong.ecnu.edu.cn/show/1435)；[大小结构理论原始研究：Growth, death, and resource competition in sessile organisms](https://pmc.ncbi.nlm.nih.gov/articles/PMC8053998/)

用于教学的通用推导可写为：稳态下 `n(D) ∝ 1/g(D) × exp[-∫ μ(u)/g(u) du]`，其中 `g(D)` 是胸径增长速度，`μ(D)` 是死亡危险率，小径边界的补充确定总量。它说明“增长更慢，停留更久；死亡更多，到达大径级更少”。这不是照片程序的已核实公式，且多物种、随机生长、随环境变化或尚未稳态时需要更完整的处理。[原始大小结构理论研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8053998/)

## 给游戏的五步实验建议（未运行）

1. 单种、等径、相同生长规则：只观察树变大及窄峰移动，说明生长过程。
2. 加持续的小径补充与背景存活：观察不同径级共存；用长寿与短寿、快长与慢长对比解释大小结构。
3. 加母树附近的扩散：保持人口过程相同，仅改变落点；观察聚集和同种拥挤。
4. 将同种与异种邻树对生长的效应分别开启：观察同位置但不同邻域的树生长差异，并追踪胸径分布与断面积。
5. 再加入幼树建立或存活的同种密度作用及物种差异：观察幼树聚集是否被削弱、稀有种能否恢复。

这是基于照片与研究思想设计的教学路线，**不是照片程序的复现说明，也没有承诺某组数值必然产生特定分布**。第三步以后的机制要保留互相独立的开关，避免把“拥挤抑制生长”和“拥挤增加死亡”绑定。[讲座模型介绍](https://tiantong.ecnu.edu.cn/show/1435)；[2021 空间模型研究](https://doi.org/10.1038/s41559-021-01440-0)

一个具体、尚未运行的简化实验可以设为：100 m × 100 m 地图、一个物种、初始 200 株胸径 1 cm 的树，每年胸径增加 0.2 cm，年存活概率 98%，每年随机位置补入 5 株胸径 1 cm 的新树，运行 100 年。暂不考虑竞争、林冠、病原和极端天气，也不将其作为照片程序的输入配置。该实验的年龄指进入模型后的时间，而非真实发芽年龄。

在这些明确规则下，持续进入的小径个体和随机死亡会形成多个径级；长期平均结构倾向于小径多、大径少。关闭补充和死亡，则等径个体保持一个向右移动的窄峰。可计算胸径分布、年龄与胸径关系、数量及胸高断面积。以后只把年增长改为 0.4 cm，或把年存活改为 95%，就可以分别检验生长和寿命对大小结构的影响。这些是规则推导和待检验预期，不是本次模拟所得结果。

## 对当前项目的衔接

以下代码状态来自本次项目检查，不属于文献事实：当前 `main.ts` 已在属性汇总中显示小径 `<5 cm`、中径 `5–15 cm`、大径 `≥15 cm` 的比例，以及平均胸径和断面积；已有图表包括群落断面积、物种数、组成、生活史、种群或功能型出生死亡及个体轨迹。尚缺独立胸径分布图、同种与异种拥挤分布、径级迁移图。因此第一轮改进可以先把已有个体胸径数据汇成可对照的直方图，再为玩家点选的树展示邻域贡献和未来生长。

代码检查还显示，`simulation.ts` 在建立及死亡中分别记录竞争与病原压力，但竞争压力混合同种和异种；大小效应用树高之比，胸径增量由高度增量乘 `1.55` 得到。若以后做与讲座相近的胸径实验，需要先明确本项目采用树高还是胸径定义竞争，并考虑把同种、异种对生长与对死亡的效应分开。此笔记不提出必须替换现有公式，具体改动应另行设计和验证。
