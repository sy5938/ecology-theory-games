# Suggested Commands

Run from repository root.

- Install exact dependencies: `npm install`
- Start local Vite demo: `npm run demo`
- Build/type-check production demo: `npm run build:demo`
- Run deterministic model tests: `npm run test:model`
- Run Playwright browser suite: `npm run test:browser`
- Inspect changes: `git status --short --branch`
- Find project files/text: `rg --files`, `rg '<pattern>' prototype-v2/src prototype-v2/tests`
- Serena memory reference check after memory maintenance: `serena memories check`
