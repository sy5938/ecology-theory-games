# 像森林一样思考 · V4.2 生态机缘版

单人森林演替游戏：玩家只经营一个真实物种，通过持续配置生长、繁殖和储备，在光照、竞争、病原菌、扰动与优势种虫害之间做生命史投资权衡。多物种共存与单种优势都是可能结局。

## 启动与关闭

在仓库根目录运行：

```bash
npm install
npm run demo
```

打开终端显示的本地地址。关闭时回到运行命令的终端，按 `Ctrl+C`。

## V4.2 核心玩法

- 每个五年周期先从 3 张随机生态机缘中保留 1 张，也可以明确放弃；同一种子重试会得到相同牌序；
- 六张首发机缘分别连接防御、结实、扩散、建立、林窗释放和风后恢复；使用要消耗储备，每周期限用一次，未使用会过期；
- 再选择一条五年后可以验证的预测：扩大下一代、抢到上层空间或守住风险缓冲；
- 再承诺生长、繁殖、储备比例；常态下锁定五年，预警期只能支付 6 点储备提前改策；
- 每五年强制暂停，判定预测命中/落空，并展示人口账、林窗账、风险账和机缘账；第一次使用完整复盘，后续改为保留地图可见的侧栏；
- 碳储备按实际经过的生态年份积累，偏储备路线有回报但不会在首周期直接封顶；
- 从四条互斥路线中选择下一周期策略，或返回工作台自定义；
- 第 20/30 年情景终点正式评分，可继续沙盒或使用同一随机种子改策略重试；
- 密闭林不再随时间自动完成，必须同时保住幼苗库并让幼树真正经历林窗释放。

## V4 性状与扰动重点

- 12 个物种拥有独立连续性状：光补偿/饱和、同化、生长、低光存活、种子质量/数量、扩散、建立、木材、抗风、恢复、防御、冠幅和成熟比例；
- 开局物种卡直接显示独特优势、代价、生态原型与参数置信度，同一功能型不再只是换名字；
- 耐荫路线改为低维持成本、低光幼苗库与林窗释放，不再用对所有死亡过程统一减伤来“假装耐荫”；
- 种子数量、质量、扩散和建立相互制约，移除先锋与耐荫之间约十倍的固定繁殖效率差；
- 台风具有强度与路径，产生落叶、断枝、折干和倒伏；结构损伤和落叶会持续影响生产，并按物种恢复力消退；
- 虫食分成持续背景取食与多年暴发期，首先压低碳收入和繁殖，重损时才造成死亡；
- 三个现有情景新增可见生态目标、实时进度和目标年结算，开局确认页说明本局问题；
- ZIP 包含 `species_profiles.csv`、`strategy_reviews.csv` 与 `opportunity_history.csv`，并在元数据中保存本局目标、性状、策略预测、机缘记录、置信度和来源说明；
- 数据库目录、证据边界与下一步计划见 `docs/ecology-data-and-v4-plan-2026-07-26.md`。

## 现有可玩内容

- 五步单页向导：选择森林情景、初始密度、生态策略、真实物种，最后确认开局；也可从第一页使用当前情景推荐配置快速开始；
- 初始密度可在每 20 m × 20 m 样方 10–400 个体之间调整，对应全图 250–10000 个系统个体；
- 默认密度：密闭森林 30（约 750 个体），稀疏森林 15（约 375 个体），先锋定殖 10（约 250 个系统个体，另加 6 个玩家幼体）；
- 100 m × 100 m 正方形地图，左下角为 `(0,0)`，SVG 绘制清晰标尺、坐标轴和主网格；
- 地图支持滚轮缩放、按住右键拖动平移和一键复位；图层栏采用紧凑宽度，控制条与事件摘要保持固定高度，不因文字变化挤压地图；
- 初始数量确定后，x/y 独立均匀抽样，使用给定数量条件下的齐次泊松点过程（HPP/CSR）；
- 高密度开局以种子、幼苗、幼树和小胸径个体为主，演替中由局部密度和胸高断面积驱动自疏；
- 个体由单个 WebGL 批次中的程序化 SDF 圆绘制，不使用 PNG 或整层树木位图；点径按树高对数映射，并在 overview / stand / individual 三个 GIS 层级间平滑变化；
- 玩家个体默认是无描边的白色矢量五角星，可使用 6 个预设色、颜色轮盘与三档大小自定义，样式保存在 `forest-map-style-v1`；
- 图层树可筛选光照、网格、物种、生活史阶段、林冠/林下、风险、死亡、选中与扰动；点击物种联动统计，双击打开对应属性表；
- 个体点击、多选、玩家幼苗/幼树一次性移栽，以及虚拟滚动属性表和密度/胸径/胸高断面积摘要；
- 统一繁殖成熟阈值为 `min(5 m, 最大树高 × 60%)`，与 10 m 林冠判定分开；
- 先锋型高光快速定殖，耐荫型以幼苗库等待林窗，广适型保持较宽光域；同一类型内部再由物种性状区分；
- 五个快速投资方案，以及每周期抽三选一的六张生态机缘牌；
- 首次进入有可跳过、可从帮助重播的三步任务式教程，覆盖地图读取、生态机缘与五年承诺；教程期间模拟暂停，移动端会自动打开当前步骤所需窗格；字体支持小/中/大三档并在本地保存；
- 第 20/30 年情景结算后解锁长期倍速，第 100 年仍有长期检查点；玩家物种灭绝后可进入观察模式，整个群落灭绝才是不可继续的终局；
- 统计窗口专注图表，不再重复显示数字指标卡；可选择物种/功能型数量、功能型出生死亡个体、功能型出生死亡率、阶段、断面积、多样性、固碳与选中对象；
- 每年记录物种、功能型与群落的出生、死亡、标准化发生率和固碳；ZIP 导出同时包含历史表、`species_profiles.csv`、事件与参数元数据；
- 普通个体死亡不逐条刷屏，突发事件即时显示，无突发事件时每五年汇总冠层优势种和玩家种群变化；
- 默认工作台采用“左侧地图、右上统计图、右下生命史策略”，地图窗格向右扩展约 35 px，统计区默认占右栏约 62%；“放大查看”仅纵向占据右栏，不遮挡地图；窗口可自由拖动、缩放、最小化和最大化，拖动后不自动吸附或归位，状态保存在 `forest-workspace-layout:v7`；窄屏使用地图加底部抽屉；
- 10,000 个体时保持 WebGL 批绘和空间索引命中，光照仍作为连续环境栅格缓存；非关键统计降低刷新频率，16× 使用分帧步进避免阻塞交互。
